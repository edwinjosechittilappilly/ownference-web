# Community conduct

Treat contributors and users with respect. Harassment, discrimination, threats, doxxing and sharing private prompts or credentials are not acceptable. Give technical feedback on behavior and evidence, not personal attributes.

Report concerns privately to the repository owner through GitHub contact or the private security reporting channel where enabled. Do not disclose sensitive details in public issues. Maintainers may remove harmful content or restrict participation proportionately; conflicts involving a maintainer should be raised with another project maintainer when available.
