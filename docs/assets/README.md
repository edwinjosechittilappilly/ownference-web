# OwnMode Web identity

OwnMode is the family. Web is the product. Always write **OwnMode**, never Ownmode or Own Mode.

**Switch to your own AI.** Local intelligence for your apps and browser. Explain real functionality before slogans; local inference is not a promise that a receiving website cannot transmit results.

## Assets

- [Family mark](family-mark.svg): one monochrome split-O, with transparent surroundings.
- [App icon](logo.svg): the same mark on a quiet paper tile. No tiny product badges.
- [Product lockup](lockup.svg): the family wordmark plus a readable product name.
- [README / social header](hero.svg): product-specific benefit, not a simulated screenshot.
- screenshot.png: captured from the running product, never illustrated UI.
- PNG icon sizes and social-card.png are exports; SVG is the source.

## Use

Charcoal **#202427**, paper **#F7F7F2**, muted text **#646B70**, borders **#DADDD8**, restrained interaction accent **#245C52**. Native apps retain system appearance. Menu icons use a transparent template mask.

Keep at least one stroke width of clear space. Use product labels instead of small extra symbols or color-only differentiation. Preserve the mark's proportions. No gradients, glowing brains, robot mascots or decorative chat bubbles. UI uses system fonts; portable SVG typography uses Arial/Helvetica/sans-serif fallbacks.

Regenerate PNG exports with **bash scripts/render-brand.sh** (requires librsvg's rsvg-convert). macOS: **brew install librsvg**.
