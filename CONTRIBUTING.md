# Contributing

Use Node.js 24 or later and `npm ci`. Run `npm run check` before proposing a change; README documents real-Ollama smoke. Keep the SDK dependency-light, browser compatible and aligned with the bridge contract. Preserve origin grants, memory-only tokens, text-only rendering, cancellation and static-path allowlisting. Contributions are under Apache-2.0.

## Workflow and review

Use a focused branch and conventional commit subjects. Describe behavior, compatibility/privacy implications and observed tests in the PR template. Add regression coverage for plausible consumer failures, not internal wiring. Run strict consumer typechecking when declarations change, and actual browser acceptance for UI changes. Never claim fake-provider tests prove live model behavior. See docs/testing.md and SECURITY.md.
